# 0009. 一覧の画面は閉じても捨てずに隠す

- ステータス: 承認
- 日付: 2026-10-13

## コンテキスト

2026-10-12 に、メモリーを減らすため、一覧を閉じたら画面（WebKit）を捨て、開くたびに作り直すようにした（閉じている間の合計が約 59MB から約 42MB に減った）。

その後、一覧を開くのに数秒かかることがあると分かった。記録を取ると、続けて開くと 0.1〜0.2 秒だが、数分あけると約 0.8 秒、約 6 時間ぶり（スリープの後）には 4.7 秒かかっていた。時間は、画面を作った後、WebKit のプロセスを立ち上げてページを読み込むまでにかかっていた。メインスレッドが止まっていたわけでも、Mac 全体が重かったわけでもなかった。

## 決定

一覧を閉じても画面は捨てずに隠す。隠している間に最初の表示（一覧のページ、詳細は閉じた状態）へ戻しておき、開いた瞬間に前の画面が見えないようにする。

2026-10-13 に測った値:

- 隠している間のメモリー（アプリと WebKit の合計）は約 64MB。捨てる作りでは約 32MB だったので、約 32MB 増える
- 表示している間に使う描画のメモリー（約 120MB）は、隠してから 1 分ほどで返される
- 開くのは、長くあけた後（110 分）でも、画面を作る時間が 0 ミリ秒になった

## 検討した代替案

- **閉じてから 10 分だけ残し、その後に捨てる**: 続けて使うときは速いが、長くあけた後やスリープの後（いちばん遅い場面）は直らない
- **今のまま捨てる**: 数秒かかる場面が残る

## 影響

- ADR 0003（軽さ）のうち、メモリーについては、この決定で約 32MB を使い続けることを受け入れた
- 画面の状態（開いているページ、開いた詳細、選んだ文字など）は閉じても残るので、閉じたときに最初の表示へ戻す処理を保つ
