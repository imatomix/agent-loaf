# 0008. AI で開発する進め方

- ステータス: 承認
- 日付: 2026-10-12

## コンテキスト

Agent Loaf は、ほとんどを AI（Claude Code）と一緒に作ってきた。進め方とルールは、作者の個人の設定と AI のメモにしかなく、ほかの人と、その人の AI には伝わらなかった。テストが通っても実機で初めて見つかった不具合や、外のツールの振る舞いを思い込みで決めて外れたことが何度もあった。

## 決定

- 大きな変更は、superpowers の brainstorming → 設計書 → 計画 → 実装 → 最後に別の AI が全体を見直す、の順に進める。小さな変更は、短い設計を会話で決めてから直す
- 横断的な決定は ADR（[docs/adr/](./)）、機能ごとの設計と計画は [docs/superpowers/](../superpowers/) に置く
- 振る舞いや構成を決める前に、類似のアプリや一般的なやり方を調べる。自分たちの考えだけで決めない。例: 終わった会話を一覧から消す決まりは、類似のアプリ 6 つの作りを比べてから決めた
- 外のツール（Claude Code・Codex・Tauri など）の振る舞いは、公式の文書と実機で確かめる。確かめた版と日付を書く（版が上がると変わるため）
- 画面やプロセスに関わる変更は、テストに加えて実機での確認までを完了とする
- ルールの本体は [AGENTS.md](../../AGENTS.md) に書く。Claude Code は `CLAUDE.md` から読み込む

## 検討した代替案

- **ルールを個人の設定にだけ置く**: ほかの人と、その人の AI に伝わらない
- **`CLAUDE.md` と `AGENTS.md` に同じことを書く**: 二重に直すことになり、ずれる

## 影響

- 個人の事情に関わる手順は、git の対象外の `CLAUDE.local.md` と `.claude/settings.local.json` に置く
- 進め方を変えたら、この ADR を新しい ADR で置き換える
