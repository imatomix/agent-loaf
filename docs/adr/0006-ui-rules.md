# 0006. 画面の決まり

- ステータス: 承認
- 日付: 2026-10-10〜2026-10-12

## コンテキスト

画面のデザインは Figma で作っている（メンテナーだけが見られる）。推測で振る舞いを足して戻したことや、アイコンの形を推測で案内して誤ったことがあった。

## 決定

- 文字に状態色を使わず、前景色（primary・secondary）だけにする。色は状態の丸やバッジなど、文字以外で使う
- 画面のデザインの元は Figma にある。描かれていない振る舞いは、推測で足さずに確かめる
- メンテナー以外が画面を変えたいときは、先に Issue で相談してもらう
- アプリのアイコンは、角まで塗った正方形のまま書き出す。macOS 26 が角丸に収めて表示する（実機で比べて決めた）

### 素材の出どころ

| 素材 | 出どころと作り方 |
|---|---|
| 一覧のエージェントのアイコン（`app/src/assets/claude-code.svg`・`codex.svg`） | ノード 157:2477・157:2480 から書き出し、背景の四角を外した |
| メニューバーのアイコン（`app/src-tauri/icons/tray/`） | MenuBarIcon から書き出した SVG を、`scripts/make-tray-icons.sh` で 36px の PNG にした |
| アプリのアイコン（`app/src-tauri/icons/`） | AppIcon（139:1982）を 1024px の正方形のまま `app-icon-source.png` に書き出し、`npx --prefix app tauri icon app/src-tauri/icons/app-icon-source.png -o app/src-tauri/icons` で作った |

## 検討した代替案

- **アイコンに角丸と余白を描き込む**: 実機で比べると、正方形のほうが見た目が良かった

## 影響

画面を変えるときは、先に Figma を見る。Figma を直したら、文字の大きさなどの値を読み直して CSS を合わせる。
