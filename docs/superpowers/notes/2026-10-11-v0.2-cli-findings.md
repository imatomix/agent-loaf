# v0.2 実装前の確認（2026-10-11、claude 2.1.296）

v0.2 設計書 10 章の確認項目の結果。テストデータは `crates/core/tests/fixtures/cli/`（パスは `/Users/tester` と `/Users/tester/.agents-monitor/marketplace` に置き換えてある）。

## 出力の形

- `claude plugin list --json`: 配列。項目は `id`、`version`、`scope`、`enabled`、`installPath`、`installedAt`、`lastUpdated`、`projectEnabled`。フォルダーのマーケットプレイスから入れたものには `readFromFolder`、`folderVersion` も付く。何も入っていなければ `[]`
- `claude plugin marketplace list --json`: 配列。項目は `name`、`source`（`directory` / `github`）、フォルダーなら `path`、GitHub なら `repo`、`installLocation`。何もなければ `[]`

## フォルダーの中身を書き換えたときの反映

- `plugin.json` の `version` を上げると、`list` の `folderVersion` はすぐ新しい版になるが、`version`（実際に使われている版）は古いまま
- `marketplace update` だけでは `version` は変わらない
- `plugin update agents-monitor@agents-monitor` で `version` が新しい版になる（`marketplace update` をしなくても）。出力は「Restart to apply changes.」
- よって更新の手順は `plugin update` だけでよい（計画 Task 6 の `update_steps` を `[Update]` にする）

## CLAUDE_CONFIG_DIR を変えての実行

- 一時的な設定ディレクトリで入れる・無効・有効・外すを行っても、`CLAUDE_CONFIG_DIR` なし・`~/.claude`・`~/.claude-personal` の `plugin list --json` は変わらなかった

## 外したときの痕跡

- `plugin uninstall` と `marketplace remove` の後、`list` も `marketplace list` も `[]` になる
- ただし `<設定ディレクトリ>/plugins/cache/agents-monitor/` に、入れたことのある版のファイルが残る。Claude Code 自身のキャッシュで、登録は外れているので動作には影響しない。設定ファイルを直接触らない方針なので、アプリからは消さない

## 無効にしたとき

- `plugin disable` で `enabled` が `false` になり、項目は残る。`plugin enable` で戻る
